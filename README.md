# Gestor de Vôlei v3.0

Este é um aplicativo de gerenciamento de partidas de vôlei, projetado para ser rápido, intuitivo e eficiente.

## 🚀 Como implantar na Vercel

Para colocar este aplicativo no ar usando a Vercel, siga estas etapas simples:

1.  **GitHub**: Primeiro, exporte este projeto para um repositório no seu GitHub (use o menu de configurações do AI Studio).
2.  **Vercel**: Vá para [vercel.com](https://vercel.com) e faça login com sua conta do GitHub.
3.  **Importar**: Clique em "Add New" -> "Project".
4.  **Selecionar Repositório**: Encontre o repositório `gestor-volei-v3` e clique em "Import".
5.  **Configurações**: A Vercel detectará automaticamente que é um projeto Vite. Certifique-se de que o **Framework Preset** selecionado seja **Vite** e o **Output Directory** seja `dist`.
6.  **Deploy**: Clique em "Deploy".

Em poucos segundos, seu app estará online com um link personalizado!

## 🛠 Tecnologias utilizadas

- React 19
- Vite
- Tailwind CSS (Modo Escuro)
- Lucide React (Ícones)
- Framer Motion (Animações)

## 📱 Funcionalidades

- Gerenciamento de times (Time A Dourado, Time B Branco)
- Lista de espera com ordem de chegada
- Cadastro e edição de jogadores
- Lógica de rotação e equilíbrio de equipes
- Modo Escuro nativo
